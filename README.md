# Java Assignments and Mini Project

This repository contains my Java programming assignments and mini project based on **Collections, File I/O, and Exception Handling**.

## 📂 Projects Included

### 1. Student Marks Record Program

**Concepts Used:**

* ArrayList
* Loops
* Conditional statements
* Finding maximum and minimum values

**Description:**
Stores student marks using an `ArrayList` and calculates the highest and lowest marks.

---

### 2. File I/O Assignment – Word Frequency

**Concepts Used:**

* FileReader
* FileWriter
* BufferedReader
* HashMap
* Exception Handling

**Description:**
Reads words from a text file, counts the frequency of each word, and writes the word-frequency results to another text file.

---

### 3. Mini Project – Employee Management System

**Concepts Used:**

* ArrayList
* File I/O
* FileReader
* FileWriter
* BufferedReader
* Exception Handling
* Classes and Objects

**Description:**
An Employee Management System that stores employee details including:

* Employee ID
* Employee Name
* Department
* Salary

The employee data is saved to and loaded from a `.txt` file. Exception handling is used to handle invalid employee data and file-related errors.
